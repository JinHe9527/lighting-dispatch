# 微信小程序配置指引

## 实现边界

本项目使用原生微信小程序页面直接调用现有 Python 服务。网站和小程序是同一业务系统的两个客户端，共用：

- `https://wuyoupaiban.cn` 上的同一套 API；
- 同一个 SQLite 数据库；
- 相同的账号、角色、排期、工单、统计、审计和业务规则。

用户在任一客户端创建、指派、开始或完成工单，另一个客户端刷新后立即看到相同结果。网站继续使用飞书 OAuth，小程序使用微信身份绑定现有系统账号。

个人主体不能使用 `web-view`，本项目因此不需要配置业务域名，也不下载 `MP_verify_*.txt` 验证文件。

## 一、准备微信小程序

1. 在微信公众平台的「开发与服务 → 开发管理 → 开发设置」取得 `AppID` 和 `AppSecret`。
2. `AppSecret` 只能写入服务器环境配置，不能放入小程序代码、网页或仓库。
3. 用微信开发者工具导入项目根目录的 `miniprogram` 文件夹。
4. 确认 `miniprogram/project.config.json` 中的 `appid` 是当前小程序的真实 `AppID`。
5. 项目后端服务选择「不使用云服务」。

## 二、配置服务器

正式服务器 `/etc/wuyou-dispatch.env` 需要包含：

```text
DISPATCH_WECHAT_APP_ID=真实小程序AppID
DISPATCH_WECHAT_APP_SECRET=真实小程序AppSecret
DISPATCH_BASE_URL=https://wuyoupaiban.cn
```

服务启动时会创建以下附加表，不修改现有用户、团队、工单和排期数据：

- `wechat_accounts`：微信 `openid` 与现有系统账号的一对一关系；
- `wechat_bind_codes`：10 分钟有效、使用一次即失效的绑定码摘要；
- `sessions`：网站 Cookie 与小程序 Bearer token 共用的登录会话。

服务端通过微信 `code2Session` 换取 `openid`。`AppSecret` 和 `openid` 不会返回给小程序。

## 三、配置服务器合法域名

在「开发与服务 → 开发管理 → 开发设置 → 服务器域名」填写：

```text
request 合法域名：https://wuyoupaiban.cn
uploadFile 合法域名：https://wuyoupaiban.cn
downloadFile 合法域名：https://wuyoupaiban.cn
```

其余字段保持空白：

- socket 合法域名；
- UDP 合法域名；
- TCP 合法域名；
- DNS 预解析域名；
- 预连接域名。

域名末尾不要添加分号、路径或端口号。保存后在微信开发者工具中保持「不校验合法域名」关闭，以真实校验结果为准。

## 四、账号绑定与共享数据

1. 用户先在网站使用飞书登录。
2. 打开网站账户菜单中的「微信小程序」。
3. 生成 8 位绑定码；绑定码 10 分钟有效，只能使用一次。
4. 用户在小程序输入绑定码。
5. 服务端把微信 `openid` 与当前飞书账号建立一对一关系，并签发原生 API 会话。
6. 小程序根据原账号角色加载同一份工单、排期和人员数据。
7. 后续打开小程序时通过 `wx.login` 自动登录，不再输入绑定码。

账号被禁止访问、取消准入或解除微信绑定时，网站和小程序的相关会话都会失效，但业务数据不会删除。

## 五、原生页面范围

小程序包含以下原生页面，并直接复用网站服务端规则：

- 今日总览；
- 创建工单及音视频附件上传；
- 工单筛选、指派、接单、开始、完成和取消；
- 日/周排班查看与组长排班调整；
- 人员状态；
- 业务统计与个人工作明细；
- 管理员账号、团队、任务、班次、分组和规则配置；
- 审计记录；
- 账号退出和解除微信绑定。

## 六、开发者工具与真机验收

提交审核前至少验证：

| 场景 | 预期结果 |
|---|---|
| 未绑定用户首次打开 | 展示 8 位绑定码输入页 |
| 正确绑定 | 进入原生首页，角色与网站一致 |
| 错误、过期、已使用绑定码 | 拒绝绑定，不产生账号关系 |
| 小程序创建工单 | 网站刷新后出现同一张工单 |
| 网站修改工单 | 小程序刷新后状态同步 |
| 指派、开始、完成、取消 | 两端结果一致且审计留痕 |
| 上传音频或视频 | 附件与网站创建的工单共用 |
| 管理员修改配置 | 网站和小程序同时使用新规则 |
| 用户被停用或解绑 | 小程序会话失效，业务数据保留 |
| 弱网与会话过期 | 显示明确错误并可重新验证 |

开发者工具通过后，再用真实手机执行预览。正式上传和提交审核前，应根据个人主体允许的服务类目填写小程序名称、简介、类目和隐私说明。
