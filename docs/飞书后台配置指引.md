# 飞书后台配置指引 ·「灯光派工」应用

> 目标:让全公司用**飞书账号登录**灯光派工系统,并接收派单私信。
> 全程约 10 分钟,只需要点网页,不写任何代码。
> 配完把 3 个值填进 `.env`,重启服务后即可使用飞书登录。

---

## 第 0 步 · 拿到你 Mac 的内网 IP(先记下来,后面要填两次)

终端里执行:

```bash
ipconfig getifaddr en0 || ipconfig getifaddr en1
```

得到类似 `192.168.1.23` 的地址。下文所有 `<MacIP>` 都替换成它。
> 建议顺手在路由器/系统设置里把这台 Mac 设为**固定 IP**,避免以后变化。

## 第 1 步 · 创建应用

1. 浏览器打开 **https://open.feishu.cn** → 右上角「开发者后台」→ 用你的公司飞书账号登录
2. 「创建企业自建应用」→ 名称填 **灯光派工**,描述随意(如"灯光师排班派工系统"),图标随意
3. 创建后进入应用详情页 → 左侧「凭证与基础信息」→ 记下 **App ID** 和 **App Secret**

> 如果这一步进不去或没有创建权限,直接跳到本文末尾「给 IT 管理员的授权清单」,转发给管理员即可。

## 第 2 步 · 添加应用能力

左侧「添加应用能力」:

1. 添加 **网页应用** → 配置页里:
   - 桌面端主页:`http://<MacIP>:8848`
   - 移动端主页:`http://<MacIP>:8848`
2. 添加 **机器人**(开关打开即可,不用配别的)——发派单私信用

## 第 3 步 · 开通权限

左侧「权限管理」→ 搜索并开通以下 2 项(直接搜中文名):

| 权限 | 干什么用 |
|---|---|
| **获取用户基本信息**(contact:user.base:readonly) | 登录时拿到真名和头像 |
| **以应用的身份发消息**(im:message:send_as_bot) | 派单/抢单时私信师傅 |

## 第 4 步 · 配置安全设置(OAuth 回调)

左侧「安全设置」→ **重定向 URL** → 添加:

```
http://<MacIP>:8848/auth/callback
```

> 必须和 `.env` 里的 `DISPATCH_BASE_URL` 完全对应,少个端口都不行。

## 第 5 步 · 发布应用

左侧「版本管理与发布」→「创建版本」:

- 版本号:`1.0.0`,更新说明随意
- **可用范围:全体员工**(这样所有团队/师傅都能登录)
- 提交发布。若公司开了审核流程,会转给飞书管理员点一下同意(私聊催一下就行)

## 第 6 步 · 回到项目,填凭据并重启

编辑项目根目录 `.env`,把注释里的三行放开并填上:

```
DISPATCH_APP_ID=cli_xxxxxxxxxxxx        ← 第 1 步的 App ID
DISPATCH_APP_SECRET=xxxxxxxxxxxxxxxx    ← 第 1 步的 App Secret
DISPATCH_BASE_URL=http://<MacIP>:8848   ← 和第 4 步回调地址同源
```

重启服务:

```bash
cd "/Users/pc/github 项目/灯光排期软件"
lsof -ti:8848 | xargs kill
python3 app/server.py
```

启动日志显示「模式: 飞书登录已启用」即成功。

## 第 7 步 · 全员开始用

- **手机**:飞书 →「工作台」→ 搜 **灯光排班软件**(应用实际名称) → 点开 → 自动以本人身份登录
- **电脑**:浏览器开 `http://<MacIP>:8848` → 点「用飞书登录」
- **你自己**:登录后页面顶部有「认领管理员」横幅,输入服务器终端上的 6 位引导码 → 你就是管理员
- **指派角色**:让灯光师们都点开登录一次 → 你在「管理端 → 人员管理」把他们设为**灯光师**并选好班次 → 系统正式跑起来

## 常见问题

- **手机打不开页面?** 手机必须和 Mac 在同一个公司 Wi-Fi;若还不行,可能是路由器开了「AP 隔离」,找 IT 放行,或改走云服务器部署(见 app/README.md 迁云章节)。
- **登录报 redirect_uri 不匹配?** 第 4 步的回调 URL 和 `.env` 的 `DISPATCH_BASE_URL` 不一致,改成完全一样(含端口)。
- **收不到私信通知?** 确认第 3 步 im 权限已开通、版本已发布、可用范围包含该员工。
- **引导码丢了?** 只要还没人认领过,重启服务就会重新打印;认领过则不再需要(管理员可在人员管理里给别人升管理员)。
